Mastermind for two

Two players play against each other. Each player secretly chooses a code of four symbols for the opponent to crack. Click a symbol to add it to the code and click a placed symbol to remove it.

After both codes are set, press Start. Players take turns guessing, with seven attempts each and a chess-style clock of 60 seconds per player. After each guess you get feedback:

  • right symbol in the right position
  • right symbol in the wrong position

The first player to crack the code wins. If a player's clock runs out, the opponent wins. If nobody cracks the code within seven attempts, the game is a draw. Both codes are revealed at the end.

Each player confirms they have read the rules to continue.
